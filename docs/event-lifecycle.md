# Event Lifecycle

```text
Observed event
-> Sent event
-> Received event
-> Attributed event
-> Reported conversion
```

## Definitions

- Observed event: user or system behavior that happened in the product/site.
- Sent event: payload emitted by browser, server, app or integration.
- Received event: payload accepted by analytics, ad platform or warehouse endpoint.
- Attributed event: received event linked to a campaign, click, session or source.
- Reported conversion: metric surfaced in a dashboard or platform report after attribution windows, deduplication and filtering.
