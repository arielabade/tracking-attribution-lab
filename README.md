# Tracking Attribution Lab

Measurement layer for marketing data quality.

## What it demonstrates

- Event lifecycle: observed, sent, received, attributed and reported.
- UTM governance for campaign comparability.
- SQL checks for duplicate events, missing campaign parameters and source consistency.

## Run

This repository is documentation and SQL-first. Review `sql/event_quality_checks.sql` and `docs/event-lifecycle.md`.
